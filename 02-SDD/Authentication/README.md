# Módulo de Autenticación y Autorización

## Descripción

Este módulo gestiona la autenticación de usuarios, administración de sesiones y control de acceso al sistema DigiDoc Travel.

- **Autenticación:** JWT (RS256)
- **Cache:** Redis
- **Eventos:** Kafka
