# Glosario

| Término | Definición |
|---------|------------|
| **Access Token** | Token JWT de corta duración para autenticar requests |
| **Refresh Token** | Token de larga duración para renovar el Access Token |
| **JWT** | JSON Web Token, estándar para tokens de autenticación |
| **SDD** | Software Design Document, documento de diseño |
| **SRS** | Software Requirements Specification, especificación de requisitos |
| **CRUD** | Create, Read, Update, Delete - operaciones básicas |
| **RBAC** | Role-Based Access Control, control de acceso basado en roles |
| **ORM** | Object-Relational Mapping, mapeo objeto-relacional |
| **API** | Application Programming Interface, interfaz de programación |
| **REST** | REpresentational State Transfer, arquitectura de APIs |
| **CQRS** | Command Query Responsibility Segregation |
| **UUID** | Universal Unique Identifier, identificador único universal |
| **bcrypt** | Algoritmo de hash para contraseñas |
| **Redis** | Base de datos en memoria para cache |
| **Kafka** | Plataforma de mensajería distribuida |
| **S3** | Amazon Simple Storage Service |
| **SES** | Amazon Simple Email Service |
| **CORS** | Cross-Origin Resource Sharing |
| **Rate Limiting** | Control de tasa de peticiones |
| **Logging** | Registro de eventos del sistema |
| **Auditoría** | Registro de acciones de usuarios |
