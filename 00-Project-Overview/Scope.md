# Alcance del Proyecto

## Alcance Incluido

### Módulos Principales

| Módulo | Descripción | Estado |
|--------|-------------|--------|
| Authentication | Autenticación y autorización de usuarios | En diseño |
| Users | Gestión de usuarios del sistema | Pendiente |
| Students | Gestión de estudiantes | Pendiente |
| Documents | Gestión documental | Pendiente |
| Visa | Seguimiento de visas | Pendiente |
| Payments | Gestión de pagos | Pendiente |
| Events | Gestión de eventos | Pendiente |
| Notifications | Sistema de notificaciones | Pendiente |
| Dashboard | Panel de administración | Pendiente |
| Reports | Generación de reportes | Pendiente |

### Funcionalidades por Módulo

#### Authentication
- Login / Logout
- Gestión de sesiones
- Recuperación de contraseña
- Control de roles y permisos
- Auditoría de accesos

#### Users
- CRUD de usuarios
- Asignación de roles
- Gestión de perfiles
- Historial de actividad

#### Students
- Registro de estudiantes
- Documentos personales
- Historial académico
- Estado de trámites

#### Documents
- Carga de documentos
- Validación documental
- Versionado
- Almacenamiento seguro

#### Visa
- Seguimiento de solicitudes
- Estados de visa
- Documentos requeridos
- Fechas límite

#### Payments
- Registro de pagos
- Estados de pago
- Facturación
- Historial financiero
